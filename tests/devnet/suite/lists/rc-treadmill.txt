# What an account that has run out of RC is charged, and what it is allowed to
# do, before and after the floor reaches consensus 0.18.0:
#
#   RC-TREADMILL-1    a payer that cannot cover a charge is not charged at all,
#                     and a slot that charged it nothing leaves its RC record
#                     alone, so its return is no longer re-anchored away.
#   RC-SLOT-GATE-1    what a slot has already charged a payer counts against
#                     what the rest of the slot may spend, so one slot cannot
#                     sell the same RC to call after call.
#   RC-UNGATED-OPS-1  an operation other than a call is refused when its payer
#                     cannot pay for it, instead of running unpriced.
#   RC-CEILING-OVERHANG-1
#                     an account owes at most what it can owe, so one that moved
#                     its HBD out comes back at the rate its ceiling allows
#                     instead of waiting out a total it can no longer owe.
#
# One test per line: the test name, then the env settings it runs with. Needs no
# inputs — the probe contract is built from modules/wasm/e2e/go_wasm.
#
# The last case waits out the ~1,440 blocks the free allowance takes to return
# the 100 RC a call costs. One block is three seconds of the test clock however
# fast the harness mines them, so that wait is 72 minutes of budget and the run
# needs DEVNET_BUDGET_CAP above the 75-minute default. Without it the case
# records itself as skipped; what the rule does is covered either way by the
# funded-payer case before it.
TestRcTreadmill_Activation DEVNET_FASTBLOCKS=1 DEVNET_BUDGET_CAP=180m
